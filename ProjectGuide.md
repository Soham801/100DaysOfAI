# One-Paragraph Problem Definition

Project:
AI Study Assistant

Problem:
Students have large amounts of study material and need
a way to ask questions about it.

Input:
PDF documents + user questions.

Processing:
Extract text → chunk text → create embeddings →
retrieve relevant chunks → send context to LLM.

Output:
Answer generated by the LLM using the student's documents.
